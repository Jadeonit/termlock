# Модель угроз и честные ограничения

## Коротко

TermLock — **ширма от любопытных домашних**, а не система безопасности.
Он закрывает экран, пока ты отошёл, и требует секрет, чтобы вернуть картинку.
Он не шифрует диск, не меняет пароль Windows и не блокирует сессию.

Если файлы действительно важны — включи BitLocker. Тогда диск бесполезен без
тебя даже при загрузке с флешки. TermLock этого не заменяет.

## Кого мы защищаем

**В зоне действия:**

- родители, родственники, гости, соседи по комнате;
- человек, который подошёл к включённому ноутбуку и хочет полистать файлы;
- случайный взгляд через плечо.

**Вне зоны действия:**

- кража ноутбука;
- доступ к диску напрямую (снял диск, загрузился с Linux);
- администратор системы;
- Safe Mode и WinRE;
- вредоносное ПО, уже работающее под твоим пользователем;
- человек, который знает, что стоит TermLock, и умеет им пользоваться.

Это не оправдание, а граница. Для домашнего сценария её достаточно.

## Что TermLock делает

- закрывает весь виртуальный рабочий стол topmost-окном;
- не даёт закрыть окно через `Alt+F4`;
- перехватывает `Win`, `Alt+Tab`, `Alt+F4`, `Ctrl+Esc`, `PrintScreen`;
- открывается по двойному нажатию Caps Lock;
- (позже) сторожевой процесс поднимает ширму, если её убили;
- требует фразу, хэш которой лежит в конфиге;
- показывает локальные CPU/RAM/диск и статусы Defender/Firewall/Secure Boot;
- (Day 7) добавляет USB-ключ и recovery-код;
- (Day 8) шлёт уведомление и, по настройке, выключает/усыпляет ПК после
  трёх неудачных попыток.

## Что он не делает

- не блокирует `Ctrl+Alt+Del` (это невозможно из user-mode);
- не удаляет другие учётные записи;
- не мешает выключить или перезагрузить компьютер;
- не мешает загрузиться в Safe Mode;
- не шифрует `%APPDATA%` и не защищает конфиг от редактирования;
- не прячет файлы от человека, который уже вошёл в систему.

## Векторы обхода и что с ними делать

| Обход | Реальность | Мера |
|---|---|---|
| `Ctrl+Alt+Del` → Диспетчер задач → снять процесс | работает | watchdog (позже), но админ всё равно победит |
| `Win` / `Alt+Tab` / `Alt+F4` / `Ctrl+Esc` / `PrintScreen` | не работают, пока ширма видна | низкоуровневый хук `WH_KEYBOARD_LL` |
| Выйти из сессии / перезагрузиться | работает | автозапуск вернёт ширму после входа |
| Другой пользователь Windows | работает, но он не видит твои файлы | не давать админку другим |
| Safe Mode | работает | не считается атакой в домашнем сценарии |
| Загрузка с флешки | работает | BitLocker + пароль BIOS + Secure Boot |
| Удалить `config.json` | сбрасывает фразу | это фича: владелец не должен блокироваться |
| Отредактировать `config.json` | можно подменить хэш | конфиг в `%APPDATA%`, не в репозитории |
| Скриншот / запись экрана | окно попадёт в кадр | `SetWindowDisplayAffinity` (opt-in, позже) |
| Второй монитор | окно растянуто на все | проверяется на Day 3 |
| Виртуальные рабочие столы | ширма на текущем | хук (Day 5) |

## Аварийный выход

TermLock намеренно нельзя «запереть»:

- `Ctrl+Alt+Del` → Диспетчер задач → снять `TermLock`;
- удалить `%APPDATA%\TermLock\config.json` и задать новую фразу;
- `TermLock.exe --disable` — разовый флаг «не стартовать»;
- `TermLock.exe --uninstall` — убрать из автозапуска.

Если после экспериментов ширма мешает, эти четыре способа работают всегда.

## Приватность

- Лог хранит время, тип события и номер попытки. Фразы и хэши туда не пишутся.
- Секретов в репозитории нет: конфиг живёт в `%APPDATA%`, ntfy-топик — тоже.
- Статы CPU/RAM/диска и проверки Defender/Firewall/Secure Boot читаются
  локально и никуда не отправляются.
- Веб-камера по умолчанию не используется. Если появится «журнал нарушителя»,
  фото будут храниться локально и с автоудалением.

## Windows 10 22H2

Поддержка Windows 10 22H2 закончилась в октябре 2025 года. Это значит, что
новые дыры в самой ОС больше не закрываются. TermLock работает и на Windows 11;
для долгой жизни проекта лучше перейти на 11 или на ESU.

## Правовое

Ставь TermLock только на свою машину. Скрытая слежка за другими людьми,
даже «для безопасности», может быть незаконной. Здесь предполагается ровно
один сценарий: владелец закрывает свой экран от любопытных.
